# URL → Markdown → LLM

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여 주고, 복사·다운로드하거나 ChatGPT·Claude에 바로 넘기는 서비스.

Linked sources:
- Prototype: [prototype.html](./prototype.html) — 승인된 화면 구성·배치·상태(빈 상태, 변환 중, 결과, 저자 없음, 오류, 긴 문서 안내, 다크, 좁은 화면)와 문구의 기준. 상단 회색 리뷰 바와 더미 데이터는 제품이 아니다.
- Decision: [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — 일반 UI는 shadcn 구성, loading/empty/error/success/disabled 상태 설계, 좁은 화면에서 column 쌓기를 따른다.
- Decision: [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) — 새 의존성 추가 시 버전 정책을 따른다.
- External: https://defuddle.md/docs — 추출 라이브러리 사용법.

## 사용자 결과

- 사용자는 URL 하나를 붙여넣고 변환하면, 페이지 제목·저자와 본문 Markdown을 한 화면에서 확인한다.
- 사용자는 그 Markdown을 복사하거나 `.md` 파일로 받거나, 프롬프트와 함께 ChatGPT·Claude 새 대화로 보낸다.
- 사용자는 라이트/다크 모드를 전환한다.

## 범위

### 1. 입력
- URL 입력창에 붙여넣고 변환을 실행한다.
- 지우기 버튼은 입력과 결과·오류를 모두 초기 상태로 되돌린다.
- `http://` 또는 `https://` 가 아닌 값, URL 형식이 아닌 값은 변환하지 않고 입력 오류를 보여 준다.

### 2. 변환
- 본문 추출은 **defuddle 라이브러리를 필수로 사용**한다.
- 변환은 서버에서 수행한다. 브라우저에서 임의 사이트를 직접 가져오면 CORS로 막히기 때문이다 (defuddle 문서의 Node.js 사용법 + DOM 구현체 방식을 따른다).
- 변환 중에는 진행 상태를 보여 주고, 그동안 변환 버튼은 비활성화된다.

### 변환 전 (시작 화면)
- 검색 엔진 첫 화면처럼 구성한다: 화면 가운데에 큰 `feedme` 워드마크와 한 줄 소개, 그 아래 넓은 둥근 URL 입력창, 그 아래 가운데 정렬된 [Markdown으로 변환]·[예시로 해보기] 버튼, 그 아래 예시 링크 한 줄.
- [예시로 해보기]와 예시 링크는 정해진 예시 주소로 바로 변환한다.
- 입력 형식 오류는 시작 화면 그대로 입력창 아래에 보여 준다.
- 변환을 시작하면(로딩·결과·접근 오류) 화면이 위쪽 정렬로 바뀐다: 헤더 왼쪽에 작은 로고, 그 아래 입력창과 [변환하기] 버튼, 그 아래 결과나 오류. 지우기를 누르면 시작 화면으로 돌아간다.

### 3. 결과 확인
- 헤더에 페이지 제목과 저자를 보여 준다. 저자를 알 수 없으면 사이트 이름(없으면 도메인)으로 대신하고, 빈 칸으로 두지 않는다. 그 옆에 알 수 있는 경우 사이트 이름·게시일, 원문 도메인 링크, 본문 글자 수를 함께 보여 준다.
- 내보내기 영역(프롬프트 선택, 열기, 복사, 다운로드)은 헤더와 본문 **사이**에 둔다. 긴 글에서도 스크롤 없이 바로 보낼 수 있게 하기 위해서다. 열기 버튼이 주된 동작, 복사·다운로드가 보조 동작이다.
- 헤더 아래에 Markdown을 **렌더링된 형태**로 보여 준다 (원문 텍스트가 아님). 제목·목록·링크·코드 블록·표가 읽을 수 있게 표현된다.

### 4. 내보내기
- **복사하기**: Markdown 본문만 클립보드에 복사하고 완료를 알린다. 프롬프트는 붙지 않는다.
- **.md 다운로드**: Markdown 본문만 파일로 저장한다. 파일명은 페이지 제목에서 만들고, 만들 수 없으면 도메인을 쓴다. 프롬프트는 붙지 않는다.
- **ChatGPT로 열기 / Claude로 열기**: 선택한 프롬프트(없으면 생략)를 본문 **앞에** 붙여 해당 서비스의 새 대화로 보낸다.
  - 프롬프트+본문이 URL 쿼리에 담을 수 있는 한도 이내면 쿼리로 직접 전달해 입력이 채워진 채 열린다.
  - 한도를 넘으면 같은 내용(프롬프트+본문)을 클립보드에 복사한 뒤 빈 새 대화를 열고, "붙여넣기(Ctrl+V)하세요"라고 안내한다. 본문은 잘리지 않는다.

### 5. 프롬프트
- 선택지: 선택 안 함(기본) / 요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘 / 직접 입력. 한 번에 하나만 선택된다.
- 프리셋은 선택한 문구가 그대로 본문 앞에 붙는다.
- "직접 입력"을 고르면 텍스트 입력창이 나타나고, 입력한 문구가 본문 앞에 붙는다. 입력창이 비어 있으면 프롬프트 없이 보낸 것과 같다.
- 직접 입력한 문구는 **저장하지 않는다**. 새로고침하거나 지우기 버튼을 누르면 사라진다.

### 6. 다크모드
- 헤더의 토글로 라이트/다크를 전환한다.

## 수용 기준

1. 공개 글 URL(예: https://stephango.com/saw)을 입력해 변환하면 제목 "Use the saw, fear the saw", 저자 "Steph Ango"와 본문이 렌더링되어 나온다.
2. 위키피디아 같은 긴 문서에서도 변환이 끝나고 제목·목록·링크·표가 렌더링된다.
3. 복사하기를 누르면 클립보드 내용이 화면에 보이는 Markdown 원문과 같다. .md 다운로드 파일 내용도 같다.
4. 프롬프트 "요약해줘"를 선택하고 짧은 글에서 ChatGPT로 열기를 누르면, 새 탭이 열리고 입력창에 "요약해줘" 다음에 본문이 이어진 내용이 채워져 있다. Claude도 마찬가지다.
5. 프롬프트가 "선택 안 함"이면 본문만 전달된다.
6. 긴 문서에서 열기를 누르면 프롬프트+본문 전체가 클립보드에 복사되고, 빈 새 대화가 열리며, 붙여넣기 안내가 보인다.
7. "직접 입력"을 선택하면 입력창이 나타나고, 다른 선택지를 고르면 사라진다. 직접 입력한 문구는 새로고침 후 남아 있지 않다.
8. 지우기를 누르면 입력창·결과·오류·직접 입력 문구가 모두 비워지고, 가운데 정렬된 시작 화면으로 돌아간다.
9. 잘못된 형식의 URL, 존재하지 않거나 응답하지 않는 주소, 본문을 찾지 못한 페이지는 각각 오류 메시지를 보여 주고, 이전 결과는 남기지 않는다.
10. 다크모드 토글로 전체 화면이 다크 테마로 바뀌고 다시 라이트로 돌아온다. 새로고침해도 선택이 유지된다.
11. 좁은 화면에서도 모든 동작(입력, 내보내기 버튼, 프롬프트 선택)을 숨김 없이 쓸 수 있다.

## 제약과 근거

- defuddle 필수 — 사용자 지정. 문서 기준 Node.js에서는 DOM 구현체와 함께 쓰고, 이 프로젝트의 서버 환경에서 제목·저자·Markdown이 추출되는 것을 scratch 복사본에서 확인했다 (defuddle 0.19.6 + linkedom, 두 페이지 모두 제목·저자 추출 성공).
- 변환 서버 실행 — 브라우저 CORS 때문. (호스팅 API `defuddle.md/`는 쓰지 않는다: 요청 한도가 있어 라이브러리 필수 요구와도 맞지 않는다.)
- UI는 [ui-composition](../../decisions/ui-composition.md)을 따른다: shadcn 컴포넌트 조합, 공통 shell, loading/empty/error/success/disabled 상태.
- 이 프로젝트는 Next.js 16이며 기존 지식과 다르다. 구현 전 `node_modules/next/dist/docs/`의 해당 가이드를 읽는다 (AGENTS.md).

## 가정 (덮어쓸 수 있음)

- 저자 없음 → 사이트 이름 → 도메인 순으로 대체 표시.
- 프롬프트 기본값은 "선택 안 함". 프롬프트는 열기에만 붙고 복사·다운로드에는 붙지 않는다.
- 다크모드: 첫 방문은 시스템 설정을 따르고, 이후 사용자의 선택을 브라우저에 저장한다.
- ChatGPT·Claude 새 대화는 각각 `?q=` 쿼리로 입력을 채우는 공개 URL을 쓴다. 쿼리 한도는 구현에서 보수적으로(수천 자 수준) 정한다. 두 서비스의 쿼리 동작은 구현 중 실제로 확인한다.
- 변환 대상은 서버가 가져올 수 있는 공개 페이지다. 로그인이 필요한 페이지는 지원하지 않으며 본문 없음/접근 실패 오류로 처리된다.
- 짧은 글을 열 때 프로토타입은 새 탭 대신 알림을 띄우지만, 실제 제품에서는 새 탭만 열려도 된다. 복사·다운로드 완료와 긴 글 붙여넣기 안내는 알림(toast)으로 보여 준다.
- 결과·URL은 저장하지 않는다. 계정, 기록, 서버 저장소는 없다.

## 범위 밖

- 계정·로그인, 변환 기록 저장, 직접 입력 프롬프트 저장 — 요청되지 않았다.
- ChatGPT·Claude 외 서비스, API 연동 — 요청되지 않았다.
- 서버 측 보안 하드닝(사설 IP 차단 등), 속도 제한, 성능 최적화 — 학습용 프로젝트의 범위 예산(AGENTS.md)에 따라 스펙이 요구하지 않는다.

## 보류 사항

- 없음.

## 남은 위험

- `?q=` 쿼리의 실제 한도와 동작은 서비스 쪽 변경에 따라 달라질 수 있다. 한도를 보수적으로 두고 초과 시 클립보드 방식으로 떨어지게 해 위험을 줄인다.
- 서버에서 가져오기를 막는 사이트(봇 차단, 로그인 벽, 클라이언트 렌더링 전용 페이지)는 본문 추출에 실패할 수 있다. 오류 메시지로 처리한다.
- 서버가 임의 URL을 가져오는 구조라 남용 소지가 있으나, 위 범위 예산에 따라 하드닝은 하지 않는다.
